# Лабораторная работа №1

## Введение в язык программирования Python

### Цель работы

Изучение основ языка программирования Python, работа с переменными, строками, списками, словарями, множествами, циклами и базовыми операциями с данными.

### Выполненные задания

В рамках лабораторной работы выполнены 11 практических заданий:

1. `00_distance.py` — расчёт расстояний между городами.
2. `01_circle.py` — расчёт площади круга и проверка положения точек относительно круга.
3. `02_operations.py` — составление арифметического выражения.
4. `03_favorite_movies.py` — работа со срезами строк.
5. `04_my_family.py` — работа со списками и расчётами.
6. `05_zoo.py` — работа со списками.
7. `06_songs_list.py` — работа со списками и словарями.
8. `07_secret.py` — расшифровка сообщения с помощью срезов.
9. `08_garden.py` — работа с множествами.
10. `09_shopping.py` — работа со словарями и ценами товаров.
11. `10_store.py` — расчёт количества и стоимости товаров на складе.

### Технические требования

Для работы с проектом необходимо:

* Python версии 3.x;
* Git;
* GitHub или GitLab для хранения репозитория;
* `pytest` для запуска автоматических тестов.

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Проверить установленную версию Python:

```bash
python --version
```

Проверить установленный `pytest`:

```bash
python -m pytest --version
```

### Примеры использования

Каждое задание запускается отдельно из корневой папки проекта.

Например, для запуска задания с расчётом расстояний:

```bash
python 00_distance.py
```

Для запуска задания с окружностью:

```bash
python 01_circle.py
```

Для работы со списком животных:

```bash
python 05_zoo.py
```

Для расчёта стоимости товаров на складе:

```bash
python 10_store.py
```

После запуска программы результаты выводятся непосредственно в терминал.

### Тестирование

Для автоматической проверки реализованной функциональности используется библиотека `pytest`.

Запуск всех тестов:

```bash
python -m pytest
```

Запуск тестов с подробным выводом:

```bash
python -m pytest -v
```

Тесты находятся в директории:

```text
tests/
```

и проверяют основные результаты выполнения заданий.
